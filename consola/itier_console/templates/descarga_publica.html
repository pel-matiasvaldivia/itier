Instalación del agente de soporte

{{ cli.nombre }}

Este instalador deja la computadora bajo monitoreo y soporte. Es automático: no hay que configurar nada.

Descargar instalador para Windows

Pasos

  1. Descargá el instalador con el botón de arriba.
  2. Abrilo con doble clic.
  3. Si aparece el aviso «Windows protegió su PC», elegí Más información y después Ejecutar de todas formas.
  4. Cuando Windows pregunte si permitís que la aplicación haga cambios, respondé Sí (si pide usuario y contraseña, hace falta una cuenta de administrador del equipo).
  5. Esperá a que la ventana se cierre sola. Listo.

Repetí estos pasos en cada computadora con Windows. Instala GLPI Agent (inventario) y Zabbix Agent (monitoreo) como servicios del sistema.
