La clave se guarda cifrada y no se vuelve a mostrar. Solo se muestran el correo y el ID de cliente de la cuenta.

📋 Cómo crearla (una vez, en tu Google Cloud)

  1. En console.cloud.google.com creá un proyecto (por ejemplo «iTier Soporte»).
  2. APIs y servicios → Biblioteca → habilitá Admin SDK API.
  3. IAM → Cuentas de servicio → crear cuenta (sin roles). En Claves → Agregar clave → JSON: pegá el contenido acá.
  4. Anotá el ID de cliente (número largo) de la cuenta: lo ves arriba una vez guardada.

🏢 Por cada cliente (lo hace un super administrador suyo)

  1. En admin.google.com → Seguridad → Controles de acceso y datos → Controles de API → Administrar la delegación en todo el dominio.
  2. Agregar → ID de cliente (el de arriba) y los permisos (scopes), separados por coma → Autorizar:
    {{ scopes|join(',') }}
  3. En la consola: ficha del cliente → Google Workspace → indicar un super administrador del cliente (la consola actúa como esa persona) → Conectar.

Es el método estándar de los proveedores de servicios: no requiere la verificación de la app por Google. El cliente puede revocarlo cuando quiera quitando esa entrada. Conviene usar una cuenta de administrador dedicada (por ejemplo soporte-itier@…) y no la de una persona.
