✉️ Correo de soporte

La consola lee este buzón por IMAP: cada correo de un cliente reconocido abre un ticket.

Cómo prepararlo en Microsoft 365 (una vez)
  1. Entra ID → Registros de aplicaciones → Nuevo registro (solo este directorio). Anotá el ID de aplicación y el ID de directorio.
  2. Permisos de API → Agregar → API que usa mi organización → «Office 365 Exchange Online» → Permisos de aplicación → IMAP.AccessAsApp → Conceder consentimiento de administrador.
  3. Certificados y secretos → nuevo secreto: pegá el valor acá (vence: anotá la fecha).
  4. Aplicaciones empresariales → tu aplicación → copiá el ID de objeto.
  5. En PowerShell de Exchange Online:
    Connect-ExchangeOnline
    New-ServicePrincipal -AppId <ID de aplicación> -ObjectId <ID de objeto>
    Add-MailboxPermission -Identity soporte@pymesenlinea.com.ar -User <ID de objeto> -AccessRights FullAccess
  6. Servidor: outlook.office365.com, puerto 993, SSL/TLS. Tarda unos minutos en tomar efecto.
