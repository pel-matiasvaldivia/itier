El secreto se guarda cifrado y no se vuelve a mostrar. Los secretos de Entra vencen (máximo 24 meses): anotá la fecha para renovarlo.

📋 Cómo crearla (una vez, en tu Entra ID)

  1. En entra.microsoft.com → Aplicaciones → Registros de aplicaciones → Nuevo registro.
  2. Tipos de cuenta admitidos: «Cuentas en cualquier directorio de la organización» (multiempresa).
  3. URI de redireccionamiento (Web): {{ redirect_uri }}
  4. Permisos de API → Microsoft Graph → Permisos de aplicación: User.ReadWrite.All, User-PasswordProfile.ReadWrite.All, Organization.Read.All.
  5. Certificados y secretos → Nuevo secreto de cliente; copiá el valor acá.
  6. Copiá el ID de aplicación (cliente) acá.

Cada cliente autoriza la aplicación una vez (consentimiento de administrador) y puede revocarla cuando quiera. Si el tenant exige más permisos para reiniciar claves, sumá Directory.ReadWrite.All.
